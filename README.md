# JARVIS — голосовой ассистент для домашнего компьютера

Полностью бесплатный офлайн-ассистент на C# (WinForms, .NET 10):
распознавание речи — Vosk (русская модель), голосовые ответы — встроенный синтез Windows.

## Запуск

```powershell
cd D:\OpenCode\Jarvis
dotnet run -c Release
```

Или запустите `bin\Release\net10.0-windows\Jarvis.exe`.

**При первом запуске** приложение скачает русскую модель распознавания речи (~48 МБ)
в папку `models/` рядом с программой. Дальше работает полностью офлайн.

## Управление

- **Слово пробуждения «Джарвис»** — микрофон слушает всегда, команды выполняются
  после обращения по имени (понимает искажения: «джервис», «дарвиз» и т.п.)
- После «Джарвис» есть **10 секунд** на команду; можно говорить одной фразой:
  «Джарвис, открой блокнот»
- Скажите «Джарвис, выключись» — ассистент уснёт, «Джарвис» — проснётся
- Кнопка с микрофоном или клавиша **F7** — вкл/выкл прослушивания
- Чекбокс «Отвечать голосом» — вкл/выкл голосовые ответы
- Слева внизу — журнал распознанных команд и ответов
- Диагностика пишется в `jarvis.log` рядом с программой

## Команды

### Управление компьютером
| Команда | Действие |
|---|---|
| «открой блокнот» / «калькулятор» / «проводник» / «диспетчер задач» | запуск программ |
| «открой документы» / «рабочий стол» / «загрузки» / «музыку» / «видео» | открытие папок |
| «открой файл отчёт» | поиск файла по названию и открытие |
| «громче» / «тише» / «громкость пятьдесят» / «громкость максимум» | регулировка звука (цифрами или словами) |
| «выключи звук» / «включи звук» | mute/unmute |
| «который час» / «какое сегодня число» | время и дата |
| «заблокируй компьютер» | блокировка |
| «спящий режим» / «заверши сеанс» | сон / выход из профиля |
| «выключи компьютер» / «перезагрузка» | питание (с отменой: «отмени выключение») |
| «закрой окно» | Alt+F4 для активного окна |

### Погода (Open-Meteo, бесплатно)
| «какая погода в Москве» / «погода завтра в Санкт-Петербурге» | текущая погода и прогноз |

### Управление браузером
| Команда | Действие |
|---|---|
| «открой браузер» / «ютуб» / «вконтакте» / «почту» / «википедию» | открытие сайтов |
| «поищи погоду в Москве» / «найди ...» / «погугли ...» | поиск в Яндексе |
| «новая вкладка» / «открой новое вкладку» | Ctrl+T |
| «закрой вкладку» | Ctrl+W |
| «обнови страницу» | F5 |
| «назад» / «вперёд» (со словом «страница/вкладка») | Alt+←/→ |
| «адресная строка» | Ctrl+L |
| «закрой браузер» | закрытие всех окон браузера (спросит подтверждение «да/нет») |

### Таймеры и напоминания
| Команда | Действие |
|---|---|
| «таймер на 10 минут» | обратный отсчёт + сигнал и голосовое напоминание |
| «напомни через час позвонить» | напоминание с текстом |
| «отмени таймер» | отмена всех таймеров |
| «выключи компьютер через час» | отложенное выключение (с отменой) |

Активные таймеры видны на левой панели.

### Свои команды (commands.json)
Файл `commands.json` рядом с программой создаётся автоматически с примерами.
Каждая команда: фразы-триггеры → действие (`url`, `search`, `app`, `file`, `folder`, `reply`).
Пример: фразы `["мой гитхаб"]`, тип `url`, значение `"https://github.com/Bezlevv"` —
и «Джарвис, мой гитхаб» откроет страницу. Изменения применяются при следующем запуске.

### Болтовня
| «ты кто» / «как дела» / «пошути» / «ты тупой» | простые ответы |

## Модели распознавания

- **vosk-model-small-ru-0.22** (~46 МБ) — лёгкая, скачивается автоматически;
- **vosk-model-ru-0.42** (~1 ГБ) — большая, распознаёт с первого раза.
  Кладётся в `models/vosk-model-ru-0.42` — программа находит её сама
  (скачивается из зеркала Hugging Face, alphacephei.com может быть недоступен).

## Требования

- Windows 10/11
- .NET 10 SDK (для сборки) — https://dotnet.microsoft.com
- Микрофон
- Для голосовых ответов: установленный русский голосовой пакет Windows
  (Параметры → Время и язык → Язык и регион → добавьте «русский», в «Голосе» скачайте русский голос)

## Структура проекта

- `Program.cs` — точка входа
- `MainForm.cs` — главное окно (тёмный интерфейс в стиле JARVIS)
- `VoiceEngine.cs` — распознавание речи (Vosk + NAudio)
- `ModelManager.cs` — скачивание офлайн-модели
- `Speaker.cs` — голосовые ответы (SAPI)
- `CommandProcessor.cs` — разбор и выполнение команд
- `SystemController.cs` — громкость, приложения, браузер, питание, файлы
- `Theme.cs`, `Controls.cs` — тема и кастомные элементы интерфейса
